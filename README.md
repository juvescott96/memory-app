# Memory App

Ein Memory-Spiel für zwei Spieler im Browser. Blue und Orange decken abwechselnd Karten auf. Wer die meisten Paare findet, gewinnt.

## Technik

- TypeScript
- SCSS
- HTML
- Vite

## Features

- Zwei Themes: Code vibes und Gaming
- 16, 24 oder 36 Karten
- Startspieler wählbar
- Punktestand und Anzeige des aktuellen Spielers
- Exit-Dialog mit Animation
- Gewinner-Bildschirm mit Konfetti (nur im Code-vibes-Theme)
- Unentschieden wird extra angezeigt
